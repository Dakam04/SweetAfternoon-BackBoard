# Sweet Afternoon バック管理

캐스트별 백(ドリンク・チェキ・シャンパン 등)을 날마다 기록하고, 기간을 정해 합계와 영수증 모양 명세를 보는 도구입니다. 화면은 모두 일본어이고, git 서버(GitHub Pages 등)에 올린 주소(https://…)로 열어서 씁니다. 시프트 관리·메뉴 관리(SweetAfternoon)와는 별개의 프로그램으로, 데이터를 주고받지 않습니다.

## 사용법

### 入力 (매일 입력)
1. 「‹」「›」 또는 날짜를 눌러 영업일을 고릅니다. 「今日」는 오늘 영업일로 돌아옵니다. 새벽 6시 전에는 전날을 오늘로 봅니다 (`config.js`의 `dayChangeHour`).
2. 캐스트를 고릅니다. 그날의 캐스트는 「基本メンバー + 그날 추가한 사람」입니다.
   - 그날만 오는 사람: 캐스트 줄 끝의 칸에 이름을 넣고 「＋ 追加」 (Enter도 가능). 전에 나온 이름은 후보로 나옵니다.
   - 그날 안 나오는 사람: 그 캐스트를 고르고 아래쪽 「この日のリストから外す」. 입력이 있으면 그 입력도 지울지 묻습니다.
   - 날짜별로 따로 저장되므로 다른 날에는 영향이 없습니다.
   - 그날 입력이 있는 사람은 기본 멤버에서 빠져도 그날 목록에 항상 나옵니다 (명세와 목록이 어긋나지 않도록).
3. 품목마다 「＋」「−」로 개수를 셉니다. 백 금액이 비어 있는 품목(ガチャ 등)은 금액을 직접 넣습니다.
4. 오른쪽(휴대폰은 아래)에 그날 캐스트별 합계가 나옵니다.

입력은 누를 때마다 이 기기에 자동 저장됩니다. 저장 버튼은 없습니다.

### 集計・明細 (기간별 조회)
- 「開始日」「終了日」로 기간을 고르거나 「今月」「先月」를 누릅니다.
- 캐스트별 입력 일수, 드링크 잔 수, 백 합계가 표로 나옵니다. 이름을 누르면 그 캐스트의 명세로 갑니다.
- 오른쪽은 영수증 모양 명세(バック明細書)입니다. 「明細」에서 전원 또는 한 사람을 고릅니다.
- 「画像で保存」: 명세 아래 버튼을 누르면 그 명세를 사진(PNG)으로 저장합니다.
  - 휴대폰: 공유 창이 뜹니다. 「画像を保存」으로 사진 앱에 넣거나 LINE으로 바로 보낼 수 있습니다.
  - PC: `明細_이름_기간.png` 파일이 내려받아집니다.
- 「明細を印刷」: 명세만 한 사람당 한 장씩 인쇄합니다. PDF로 저장해 LINE으로 보낼 수도 있습니다.
- 「CSV書き出し」: 이 기간의 캐스트별 집계를 엑셀용 CSV로 내려받습니다.

### 設定
- 基本メンバー: 매일 입력 화면에 나오는 고정 멤버입니다. 직접 추가(「＋ キャストを追加」), 이름 수정, 순서 변경(↑↓), 빼기(×)만 하고, 시프트표에서 자동으로 늘어나지 않습니다.
  - 그만둔 사람은 ×로 뺍니다. 다음 날부터 목록에 안 나오고, 지난 기록과 입력이 있던 날의 목록에는 그대로 남습니다.
  - 그날만 추가했던 사람이나 뺐던 사람을 같은 이름으로 다시 추가하면, 지난 기록과 이어집니다.
- 品目とバック: 품목 이름과 1개당 백 금액. 금액을 비우면 입력할 때 금액을 직접 넣는 품목이 됩니다.
- 삭제해도 지난 기록과 명세에는 이름이 그대로 남습니다.
- 백 금액을 바꿔도 이미 입력한 날의 금액은 그대로입니다 (입력한 때의 금액을 같이 저장).
- 「ドリンク杯数」로 세는 품목은 ドリンク・ショット입니다. 바꾸려면 `config.js`의 `drinkItems`를 고칩니다.

## 다른 기기로 옮기기·백업

「データ移行」 → 「データを書き出す」로 JSON 파일을 만들고, 다른 기기에서 「データを読み込む」로 읽습니다. 같은 날짜는 덮어쓰고 나머지 날짜는 남깁니다. 급여 기록이므로 **월말마다 내보내 두는 것**을 권장합니다.

## 주의

- 저장 위치는 지금 쓰는 브라우저입니다. 관리용 기기 1대를 정해서 입력하세요. 여러 기기에서 각각 입력하면 기록이 합쳐지지 않습니다.
- 주소(도메인)가 바뀌면 브라우저가 다른 사이트로 인식해 저장 내용이 보이지 않습니다. 옮기기 전에 「データ移行」으로 내보내 두세요.
- 아이폰은 홈 화면에 추가해서 쓰세요. Safari 탭으로만 쓰면 7일 넘게 열지 않았을 때 iOS가 저장 내용을 지울 수 있습니다.

## 파일 구조

```
index.html          화면 틀 (문구는 js/texts.js에서 채움)
css/style.css       화면·인쇄 스타일 (영수증 모양 포함)
js/config.js        설정 (저장 키, 날짜가 바뀌는 시각, 드링크로 세는 품목, 처음 품목과 백 금액)
js/texts.js         화면·명세 문구
js/app.js           동작
```
